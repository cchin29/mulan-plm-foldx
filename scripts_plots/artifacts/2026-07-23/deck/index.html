Dataset & methodology · Datasets and mutations

Dataset and mutation generation

  • Curated experimental ΔΔG from SKEMPI 2.0 — measured Kd, not synthetic (ΔΔG = −RT·ln(Kd_mut/Kd_wt))
  • We now run the full set, not the paper's S1102/S1131 subsets (lineage: S1131 ⊂ S4169; S2003 = non-Ala half)
  • Single-chain-per-partner restriction (MuLAN takes one sequence per partner)
  • Single- and multi-point mutations
How a data point is built
WT + mutant sequence → FoldX BuildModel generates the mutant structure (FoldX arm) → PLM embedding → ΔΔG head
  • The "mutations are generated" step is literally the FoldX mutant-structure build; the ΔΔG labels themselves are measured, not generated.

Dataset & methodology · Metric

Pooled Pearson vs per-structure Spearman

Per-structure Spearman answers the design question (rank mutations within a complex). Pooled Pearson is inflated by the spread between complexes — exactly where homology leakage hides. Smaller numbers = the evaluation getting stricter, not the model getting worse.

Interaction sites · Interpretation

Attention-interface localization vs ΔΔG accuracy

ESM-C 6B is the best ΔΔG arm yet near-worst at localizing interfaces — ~0.19 below its own 600M sibling. The two are different read-outs of the same head.
  • Mechanism: large PLMs delocalize — a rich pooled vector wins ΔΔG, so the head no longer needs to concentrate attention at the interface (no localization term in the loss).
  • Distinct from ESM3 (massive-activation outliers, below chance) — ESM-C 6B's embeddings are healthy; its drop is delocalization, not an artifact.
  • Takeaway: "attention recovers interfaces" is Ankh-specific, not a property that scales — worth flagging wherever the paper's interpretability claim is cited.
Summary

Summary of findings

  • Comparison: base PLMs collapse out-of-family; a cheap FoldX channel puts a frozen sequence model on the leakage-controlled frontier (CATH 0.411); ESM-C 6B + FoldX leads.
  • Dataset: full experimental SKEMPI, FoldX-generated mutant structures, evaluated under progressively stricter homology hold-outs.
  • Attention: reproduced the paper exactly; no PLM beats Ankh on interface localization and scaling hurts — the signal is Ankh-specific.
